# 头像名片卡 · 设计文档

> 版本：2026-09-13（commit `ef9a9a4`）
> 位置：导航栏左上角头像
> 状态：已上线（GitHub Pages + Cloudflare Pages 双管线）

---

## 一句话

点击导航栏头像，头像放大并与一张 Anthropic 暖金风格的个人名片卡连为一体；名片是"身份容器"（首页是"内容流"容器），只放首页没有的信息。

## 交互一览

| 交互 | 效果 |
|---|---|
| 鼠标靠近头像（200px 内） | 金色光环朝鼠标方向"顺毛"倾斜，头像微微转向鼠标（Josh Comeau 彩虹头图的致敬） |
| 悬停头像 | 放大 1.12x + 金色光环增强 |
| 点击头像 | 放大 1.4x，下缘 1/3 嵌进卡片顶部左侧；导航栏标题淡出让位（"身份转移"——名字同一时刻只出现在一处） |
| 再点一次 / 点空白 / ESC | 卡片收起，标题淡回 |
| 按 `A` 键 | 键盘开关名片（与 `/` 搜索快捷键形成键盘语言） |
| 连点头像 5 次（30 秒内） | 头像位置炸 90 片金色彩带 |
| 在头像上停留 3 秒 | 静静解锁"顺了顺毛"秘密 |

## 名片卡内容（自上而下）

1. **名字 + 简介** —— 名字为衬线字体（Georgia/宋体系），Anthropic 编辑感
2. **统计行** —— 文章数 · 已运行天数（按最早一篇文章日期自动计算）· 标签数
3. **签名句** —— 取自 `_config.yml` 的 `subtitle`，衬线斜体 + 金色左边框
4. **发文热力** —— 近 20 周 GitHub 式贡献格（140 格，5 级金色深浅），构建时从全部文章日期聚合，零维护；悬停显示"日期 · N 篇"
5. **精选文章** —— 作者策展（区别于首页时间线），带金色星标
6. **访问计数** —— 不蒜子（懒加载：首次打开名片才加载脚本）
7. **秘密进度** —— 七个菱形点 + "秘密 X/7"
8. **按钮组** —— 回首页（实心金主按钮）/ 随便看看（52 篇随机漫游）/ Github / Email / 复制邮箱

## 日常怎么改

### 换精选文章
编辑 `themes/fancy-avalanche/_config.yml` 的 `avatar_card.pinned`：

```yml
avatar_card:
  pinned:
    - title: 显示的标题
      url: /2026/09/12/文章的permalink/
```

留空整个区块自动隐藏。新增社交链接在 `social:` 下加一行即可，图标自动匹配（支持 github/email/twitter/zhihu/weibo/rss/bilibili/telegram，未识别的显示 link 图标）。

### 改配色
卡片全部用专属暖金变量，**不受鲸蓝/素瓷主题变体染色**：
- `--fa-gold: 212 168 83`（#D4A853 主金）——定义在 `style.css` 的 `:root` 和 `.dark`
- `--fa-gold-deep: 184 141 53`（hover 深金）

### 调整交互参数
全在 `themes/fancy-avalanche/source/js/main.js`：
- 顺毛感应范围：`var range = 200`（mousemove handler 内）
- 顺毛判定时长：`setTimeout(..., 3000)`
- 连点彩蛋：`btn._clicks` 的 30000 窗口 / `>= 5` 次数
- 老朋友门槛：`opens >= 10`
- 彩带粒子数：`__faConfetti` 的 `i < 90`

### 新增一个秘密
1. `FA_SECRETS` 数组加 `{ id: 'xxx', name: '名字' }`
2. 在合适的触发点调用 `window.__faSecretFound('xxx')`
3. 完事——进度、toast、集齐彩带都是自动的

## 已知设计决策（改前必读）

- **头像与卡片嵌合**：卡片 `top: calc(100% - 13px)` + 头像 `z-index: 2`，改放大倍数（scale 1.4）需同步调 `top` 和 `.avatar-pop-head` 的 `padding-left: 5.6rem`
- **标题让位**：`#nav-site-title.avatar-yield` 同时做位移和淡出，由 `__faAvatarSet` 统一切换
- **金色不用 `--fa-rgb-500`**：那是主题变体色（鲸蓝/素瓷会变蓝变绿），名片一律 `--fa-gold`
- **EJS 坑**：此 Hexo 版本 `site.posts.map('path')` 报 "iterator is not a function"，要用 `site.posts.toArray().map(function (p) { return p.path; })`
- **部署坑**：卡片全部用自定义 CSS 类而非新 Tailwind 类，所以 GitHub Actions（只跑 `npx hexo generate`，不编译 Tailwind）不会缺样式；如果以后要加 Tailwind 类，记得本地 `npm run build` 后把 `tailwind.css` 一并提交
- **不蒜子**：不同域名计数分开记（github.io 与 pages.dev 各自累积），属正常
